## prompt_en 写法（Seedance 2.0）

**一个分镜 = 一条 Seedance 视频。prompt_en 里不要排 Shot 1 / Shot 2 这种多镜头切分** ——
时长、字幕、合并全是按分镜算的。每条 prompt_en 只描述**一条连续镜头**。

按下面五段顺序写，连成一整段英文：

**① 开场声明**（第一句，也是质量杠杆最大的一句）—— 先声明格式和风格，再描述内容：
   One continuous shot, no cuts, no zoom, photorealistic, 35mm film grain
   要手持主观感就再加 handheld, unstabilized, natural head movement；
   **只有这一镜真的不移动**才加 locked-off tripod, no camera shake ——
   它等于选了「固定」这一种运镜（见 ④ 一镜一运镜），
   和 push in / pan / track 不能同时出现。
   ⚠️ `photorealistic, 35mm film grain` 是**写实风格**的写法。用户指定了非写实风格
   （2D 日漫、3D 国风漫画、水墨、粘土…）时**必须把这两个词换成对应的风格词**，
   不能并存 —— 同一句里既写 photorealistic 又写动漫风是语义冲突，模型只会挑一个跟。

**② 主体 + 场景 + 空间**
   - 主体：年龄/发型/服装/体态等外貌特征；同框多人时写清怎么区分。
     **身份必须逐镜原样重写** —— Seedance 把每个镜头当冷启动处理，
     「他」「同一个人」「上一镜里那个女人」一概无效
   - **先定义主体，再用标签指代**（这一镜的 prompt_en 开头定义，本镜内后续全用标签）：
     `将@图片1中穿红色连衣裙、戴草帽的女人定义为<主体1>` —— 标签也可以直接用名字
     （`定义为张红`）或身份（`将@视频1中的高个子男人定义为警察，将另一个矮个子男人定义为小偷`）。
     多个主体**分别定义**，标签要唯一且稳定，定义之后**每次提到都用同一个标签**，
     不要中途换成「他」「那个女人」
   - **定义句每一镜都要重写一次** —— 一个分镜就是一次独立生成，上一镜定义过的标签
     这一镜不认。同一个角色跨镜要用**同一套定义文字和同一个标签**，别改措辞
   - **没有单独定义主体的简单场景**，每次提到主体都写成 `<主体N>@图片N`
     （例：`张三@图片1`），把主体和素材绑在一起，不要只写名字
   - **不能用 Asset ID 代替 `@图片N` / `@视频N`**：模型看不到 asset id 和素材内容的对应关系，
     写进提示词等于没写
   - 定义要**简洁且不自相矛盾**：同一个主体不要出现互相打架的特征（又说穿红裙又说穿风衣）；
     空间关系能靠参考图表达就别写成一长串文字
   - 素材引用统一写成 `@图片N` / `@视频N` / `@音频N`（**不要用尖括号** ——
     `<>` 是音效的符号位，`<远处传来狗叫声>`；`<>` 只用在 `<主体N>` 上），
     直接指代随请求发出的第 N 个该类型素材
     （编号对应 content 数组里第 N 个 `image_url` / `video_url` / `audio_url`，
     三类各自从 1 开始数）。人物锚在 `@图片N` 上，运镜或动作参照写 `@视频N`，
     环境声参照写 `@音频N`
   - **重要素材前置**：越需要精准还原的素材，在 prompt_en 里**出现得越靠前**。
     主角的脸写进第一句主体描述，次要道具、环境参考往后放 ——
     位置靠前的引用模型跟得更紧，堆到句尾的引用经常被当成可选项
   - **同一个主体给了多张图就一次点全**，并说明每张图管哪一面 —— 模型会把它们
     合成同一个主体，而不是当成三个东西：
     「提取@图片1@图片2@图片3的相机，把背景换成白色…清晰展示正面侧面以及背面」。
     ⚠️ **这条只适用于物体/产品**。人物只用**大头照 + 全身照**两张
     （面部参考大头照，妆造体态参考全身照），**禁用三视图/多视图** ——
     人物多视图会触发 ID 漂移和双胞胎
   - **断句防歧义**：`@图片N` / `<主体N>` 后面**不要紧接动词或方位词**
     （`@图片1跑向…`、`@图片2位于…` 会被数字粘连读歧义），
     要么补个名词隔断（`@图片1中的女子跑向…`），要么写成 `<主体N>`
   - 主体不限于人：产品、道具、场景都可以这样锚定，`提取@图片N的X` 还能顺带
     把它从原背景里抠出来重新布景
   - **一镜可以同时点多张图，每张承担不同职能** —— 主体多视角、场景图、服装图、
     道具图、分镜构图参考、标识图都支持。给每张图写清它管什么，别笼统写「参考这些图」：
     *场景设定在@图片4中的餐厅内，店内人来人往。@图片1里的女孩身着@图片2中的服装，
     正在整理柜台上的物品。@图片3中的男孩是一位顾客，他走上前……
     @图片5中的标识始终显示在画面的右下角。*
   - **编号 = 素材的上传顺序**，一旦定下全片不要重排 —— 编号错位比不引用更糟，
     角色会锚到别的图上
   - 标识/水印类图片可以钉在固定位置（`始终显示在画面的右下角`），
     但**别钉在下三分之一**，那里留给后期烧的字幕
   - 引用 @图片N 时**叠加身份锁定短语**（实测能压住脸部漂移，几句一起堆效果更好）：
     the same character, maintain exact appearance from the reference image,
     no deformation, no drift, no face morph, do not alter clothing category or primary color
   - 场景：地点、时代、天气、时段，以及环境里正在发生的变化。写能拍到的细节
     （湿沥青反光、钠灯、雨丝、体积雾），不要写「氛围不错的街道」
   - 空间：景别 + 主体在画面中的位置 + 前中后景层次，以及这些在这一镜里**怎么变**；
     并写上 lower third of frame kept clean and unobstructed
     （**不要写 for subtitles** —— 提到 subtitles 模型会真去渲一行字，见 subtitle-safe-area）

**③ 时间轴节拍** —— 把这一镜按秒切成 2-3 段写动作：`0-3s: … 3-6s: … 6-10s: …`。
   这是让镜头内部有推进、而不是一个凝固画面的关键。
   - 动词要具体有力（slides / plants / snaps / crumples / weaves），
     不要用「走过去」「看着」「拿起」这类泛动词，模型对软动词一律给平庸结果
   - **优先低缓连续的小动作**，规避狂奔 / 大跳 / 剧烈翻滚这类高爆发动态 ——
     动作越剧烈越容易崩肢体。要具体有力指的是**动词选得准**，不是幅度大
   - **动作按肢体细化 + 程度量化**（手/腿/头/肩背 + 幅度/速度/力度），
     并写清前后惯性怎么接上（「借着转身惯性顺势抬手」）
   - **状态只前进不回退**：湿了不会自己干，签过字的合同不会回到没签 ——
     镜与镜之间的状态推进要写进画面里
   - 需要慢动作就写 RAMPS TO SLOW MOTION，恢复时写 SNAPS BACK TO REAL TIME
   - **要禁止什么就给替代**：「不要哭」很弱，「眼眶红着但没落泪，喉结动了一下」才可执行

**④ 镜头 + 光线 + 色调**
   - **一镜一运镜**：单个镜头只指定**一种**运镜（推/拉/摇/移/跟拍/固定 六选一），
     禁止叠加 —— 「先固定、后半段推进」这种写法模型只会跟一个，结果不可控。
     注意和 ① 的机位声明区分：`handheld, unstabilized`（手持质感）
     可以和任何一种运镜并存；但 `locked-off tripod` / `static` **就是「固定」**，
     一旦写了它，同一镜里再出现 push in / pan / track 就是自相矛盾
   - 运镜术语不能含糊（哪个词占主导模型就跟哪个走）：dolly（机器前后移动）≠ zoom（焦距变化）；
     pan（原地旋转）≠ truck（横向平移）；bird's-eye 是严格垂直俯视，aerial 说的是高度；
     static 是严格的（零移动、零变焦、零改焦），只要有一样发生就别写 static
   - **明确否定不要的镜头行为** —— Seedance 很吃这一套：no cuts / no zoom / no stabilization /
     no smoothness at all；要真实皮肤和布料质感就加 no 3D, no cartoon, no VFX aesthetic；
     **每一镜都要带上** no subtitles, no captions, no on-screen text, no watermark, no logo
     （字幕是后期烧的，模型再渲一层就重叠）。
     ⚠️ 否定**只用在镜头行为和风格上**；画面内容不要用否定 ——
     想要空街就写 empty street at dawn，不要写 no people
   - 光线只给一个动机光源和方向。不要同时写正午强光和霓虹夜景，模型只会选一个
   - **不写情绪形容词，写造成这个情绪的成因**（epic / moody / 电影感 / 高级感 不约束画面）：
     ✗ 压抑的氛围 → ✓ 低照度主光、暗部只提亮两档、空气里有体积雾、镜头长时间不切
     ✗ 温馨的一刻 → ✓ 暖色边缘光从窗右侧进来，浅景深，焦点只落在两只手上

**⑤ 声音**（末尾一句）：环境声 + 关键动作音。不需要音乐就直接写 no music, only raw SFX；
   需要也只写质地（low piano texture underneath），不要点名要一整首配乐。

**长度**：承担关键叙事的镜头 150-220 词，过渡镜头和空镜 80-140 词
（这条覆盖系统提示词里的 50-120 词 —— Seedance 是少数写得越结构化越准的模型）。

**忌讳**：一个镜头里排 4 个以上同时发生的动作（运动会散架，拆成两镜）；
画面里出现需要看清的文字或 logo（渲不准，文字一律后期烧 ——
唯一例外是本次明确指定了广告语，见 in-video-slogan）；
同框人脸超过两张（脸越多漂得越厉害，第三个人放画外音或只给背影）。
