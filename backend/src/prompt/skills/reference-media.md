## 参考视频 / 音频（本片带了这类素材）

1. **要用就在 prompt_en 里点名**：`@视频N` / `@音频N`。不写编号，模型不会主动去看
2. **参考视频拿来对齐运镜和动作**：写清楚要学的是哪一层 ——
   「camera movement matching `@视频1`」（学运镜）还是
   「the same gesture and rhythm as in `@视频1`」（学动作），不要笼统写「参考 `@视频1`」
3. **两个人有持续肢体接触的动作**（搀扶、拥抱、拉扯）模型自己排很容易穿帮，
   这类镜头优先挂一个动作参考视频
4. **参考音频用来定环境声底子**：`@音频1` 写成 ambience reference，
   不要指望它当配乐；人声和音乐不要混在同一条参考音频里
5. **参考音频也能拿来克隆音色**，但光写编号不够 —— 要**紧跟一句中文音色特征描述**，
   实测匹配度明显提升：
   `使用@音频1低厚温润带细碎颗粒感中年男声的音色说：「…」`
   音色描述至少覆盖三项：音高（低厚 / 清亮）、质感（温润 / 沙哑 / 带颗粒感）、
   年龄性别（中年男声）。只写 `@音频1` 不描述音色，还原会飘
6. **音频引用同样吃「重要素材前置」**：要克隆音色的那句写在台词前面，不要放段尾
