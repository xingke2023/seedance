## 解说片配画手法
**一句话原则：解说负责论点，画面负责证据和代价，两者不要说同一件事。**

1. **声画关系配比大约 2 : 6 : 2**
   - 同义（说什么拍什么）：只在必须建立事实时用，用多了整片就是有声 PPT
   - **补足（主力）**：解说讲结果，画面给过程或代价 —— 讲「他二十年没回过家」，
     不给人，给那间一直没动过的房间
   - 反差（解说讲光鲜数字，画面给废墟）：观点从这儿来，但全片最多两三次
2. **闭眼自检**：把这一镜的旁白念一遍再闭上眼，如果脑子里第一个浮现的画面正好是你写的那个，
   这个镜头就该换掉
3. **画面要像堪景的人写，不像素材库管理员写**：
   ✗「城市下雨的蒙太奇」→ ✓「雨横着打在公交车窗上，蓝调时刻，乘客的脸虚焦，
   红绿灯的颜色透过玻璃洇开」。模板：主体 + 动作姿态 + 环境 + 光线 + 年代质感。
   判据是**自己想象不出一张具体照片，模型也生成不出来**。三个忌讳：情绪词（「归家的感觉」）、
   意图词（「象征性地穿过那道门」）、形容词堆砌（「温暖美好的时刻」）
4. **一个镜头只安排一个有效瞬间**：在动作自然结束**之前**收，结束在一个眼神上，
   不要把动作做完做满 —— 做满了就像素材用尽，不像有意为之
5. **10-15 秒的镜头内部必须有变化**：观众吸收一个画面约 3 秒，超过 5 秒画面不变注意力就散。
   靠缓慢运镜、光线推移、前景有东西经过、人物位置改变来撑住这十几秒，
   别写成一个从头到尾一动不动的画面
6. **旁白语速按段落浮动**（以系统提示词的每秒 3.5 字为基准）：钩子段可以冲到 4.5 字/秒，
   讲解段保持 3.5，**关键洞察压到 3 字/秒**，并在这一镜结尾留 1-3 秒不说话让画面自己待着 ——
   要留白的那一镜，narration_script 就相应写短
